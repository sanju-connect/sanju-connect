## 👨‍💻 About Me

Hey, I'm **Sanju Ghosh** — a Computer Science student and aspiring software developer from Siliguri, West Bengal, India.

I'm building my foundation in programming, problem-solving, and software development, with a long-term interest in creating technology that is useful, thoughtful, and impactful.

I believe that becoming a better developer isn't just about writing code. It's about learning how to think, asking better questions, experimenting with ideas, and consistently improving.

- 🧠 **Problem-solving:** Developing my Data Structures and Algorithms skills.
- 💻 **Programming:** Exploring Python, C, C++, and Java.
- 🌐 **Web development:** Learning HTML, CSS, and JavaScript.
- 🤖 **Artificial intelligence:** Exploring the possibilities of AI.
- 🌍 **Open source:** Working toward contributing to the developer community.
- ♟️ **Beyond code:** Chess, reading, science, creativity, and entrepreneurship.

I'm at the beginning of building my public project portfolio. This profile will grow as I learn, experiment, and publish my work.

## 🎯 My Philosophy
